Read the certificate image

Open the full-size brochure spread to inspect each title, reference number, issue date and stated scope. Request an electronic copy by title if a detail is difficult to read.

Match documentation to the equipment

Company certificates and equipment nameplates describe different subjects. For a particular weighbridge, record the model, capacity, scale interval, indicator and required handover documents for comparison.

Keep a traceable project file

Archive certificates, approved drawings, equipment schedules and acceptance records under the project reference. Keep document dates so maintenance staff can trace the original configuration when replacing components.
